고객이 보게 되는 순서

        

          
① 링크 열기휴대폰은 크롬(아이폰은 사파리)으로 엽니다. 카카오톡에서 누르면 자동으로 넘어갑니다.

          
② 계약 내용 확인업무와 보수를 확인하고 필요한 항목(기장계약은 지급일)을 고릅니다. 아래에 실제 계약서가 그대로 보입니다.

          
③ 인적사항 입력상호(성명), 사업자번호(생년월일), 주소, 대표자를 적습니다.

          
④ 서명 또는 날인손가락·마우스로 서명하거나 도장 찍은 종이를 사진으로 올립니다.

          
⑤ PDF 만들기·보내기‘보내기’를 누르면 카카오톡·메일로 바로 전송됩니다. PC는 저장 후 메일에 첨부합니다.

개인·법인 기장대리월정액, 업무범위지급일 선택, 서명계약서 2쪽 + 확인서 1쪽

              
상속세 신고·조사대행피상속인, 총 보수(착수금 기본 50%), 성공보수 조항서명계약서 + 전자서명 확인서

              
세무조사 대행조사 종류, 총 보수(착수금 기본 50%)서명계약서 + 전자서명 확인서

              
업무 대행업무내용, 총 보수(착수금 기본 50%), 지급시점서명계약서 + 전자서명 확인서

            

          
2. 처음 한 번: 프로그램 올리기

          
    
            
  1. index.html 파일을 GitHub Pages에 올립니다. 서버 프로그램이나 데이터베이스는 필요 없습니다.
    2. 
            
  2. 올린 주소를 ‘링크 만들기 → 배포 주소’에 한 번 입력합니다. 이후에는 자동으로 기억됩니다.
    3. 
            
  3. ‘사무소 열쇠’(12자리)를 PC마다 한 번 입력합니다. 직인·입금계좌는 파일 안에 암호화되어 있어 열쇠 없이는 볼 수 없고, 열쇠는 서명 링크에만 담깁니다.
    4. 
            
  4. 고객 정보와 서명은 고객의 휴대폰 안에서만 처리되어 PDF로 만들어지며, 어떤 서버에도 저장되지 않습니다.
    5. 
          

          
3. 계약할 때마다: 링크 보내기

          
    
            
  1. 계약 종류와 조건을 입력하고 ‘서명 링크 만들기’를 누릅니다.
    2. 
            
  2. ‘카카오톡 안내문 복사’를 눌러 고객 카톡방이나 카카오톡 채널 상담창에 붙여넣습니다.
    3. 
            
  3. 발송코드(8자리)는 발송 이력에 자동 저장됩니다.
    4. 
          

          
4. 회신받았을 때: 확인하고 보관하기

          
    
            
  1. 회신 PDF 마지막 쪽은 전자서명 확인서입니다. 그 앞은 계약서 본문입니다.
    2. 
            
  2. ‘발송 이력·검증 → 회신 PDF 검증’에 받은 파일을 그대로 올립니다. 지문값·발송코드·계약 조건이 자동 대조됩니다.
    3. 
            
  3. PDF는 고객 폴더에 받은 이름 그대로 보관합니다.
    4. 
          

          
5. 기록은 어디에 남나요

          
    
            
  • 발송코드(8자리): 서명 링크 내용으로 계산한 값입니다. 링크를 만든 PC 브라우저의 ‘발송 이력’과 회신 PDF 확인서에 남습니다. 보낸 카카오톡·메일 속 링크로도 언제든 다시 계산할 수 있습니다.
    • 
            
  • 문서 지문값(SHA-256): 고객이 서명하는 순간 고객 기기에서 계산됩니다. 회신 PDF 확인서에 인쇄되고, 계산에 쓰인 원본 기록이 PDF 파일 속에도 함께 들어갑니다.
    • 
            
  • 받은 파일 지문값: 검증할 때 받은 PDF 파일 전체의 지문값을 발송 이력에 기록합니다.
    • 
            
  • 서버에는 아무것도 저장되지 않습니다. 원본 PDF와 고객이 보낸 카카오톡·메일 원문을 함께 보관하시고, 발송 이력은 ‘백업 파일 저장’으로 주기적으로 받아 두세요.
    • 
          

          
6. 법적 효력

          
「전자서명법 제3조」 ① 전자서명은 전자적 형태라는 이유만으로 서명·기명날인으로서의 효력이 부인되지 않고, ② 당사자 간 약정으로 전자서명을 선택한 경우 서명·기명날인으로서의 효력을 가집니다. 모든 계약서에 【전자계약】 조항을 두었고, 고객이 서명 전에 별도로 동의하도록 했습니다.

          

          
「전자문서 및 전자거래 기본법 제4조 제1항」 전자문서는 전자적 형태로 되어 있다는 이유만으로 법적 효력이 부인되지 않습니다.

          
7. 자주 받는 질문

          
    
            
  • 카카오톡에서 안 열리거나 PDF가 안 만들어져요. 카카오톡 안의 화면은 파일 저장을 막습니다. 화면 맨 위 [크롬·사파리로 열기]를 누르거나, 링크를 복사해 크롬(아이폰은 사파리)에 붙여넣어 열면 됩니다.
    • 
            
  • 도장을 꼭 찍어야 하나요? 손 서명만으로 충분합니다. 인감날인을 원하시는 고객은 종이에 찍은 도장을 촬영해 올리면 됩니다.
    • 
            
  • 주민등록번호 칸이 없어요. 「개인정보 보호법」 제24조의2에 따라 계약서에는 생년월일만 받습니다. 신고서 작성에 필요한 주민등록번호는 신고 단계에서 별도로 받으세요.
    • 
            
  • 링크를 다시 보내야 하나요? 같은 링크는 몇 번이든 다시 열 수 있습니다. 조건을 바꾸려면 새 링크를 만드세요.
